# Predictive Trust Monitoring System

## Overview
This project is a web-based data product built in Streamlit to support an end-to-end OSEMN workflow for identifying early signs of declining customer trust.

## Files Included
- app.py
- requirements.txt
- assets/ folder with screenshots
- paper document

## How to Run
1. Open Command Prompt in the project folder
2. Install packages:
   pip install -r requirements.txt
3. Launch the app:
   streamlit run app.py

## Core Features
- Upload and preview raw customer experience data
- Explore variables and summary patterns
- Clean and preprocess data
- Engineer trust-risk features
- Run a trust-risk classification pipeline
- Generate visualizations
- Execute the workflow step by step or in full
- Download processed outputs
